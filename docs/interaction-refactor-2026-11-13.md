# 豆伴交互与功能重构审查

2026-11-13 的本地预览审查记录。保留同期的数字进度与刷新修复，并兼容本工作区的抓取逻辑修复；后者见 `backup-errors-2026-11-13.md`。当时未提交或推送，后续主分支复核见下文；扩展商店版本尚未发布。

## 审查结论

原插件的数据快照、迁移回执等核心机制已有较完整的回归保护。主要问题集中在前端异步状态、反馈不完整、可访问性、数据管理与后台任务的协调，以及不可信备份内容的展示。本次保留已验证的采集与快照结构，重构四个主要页面和共用交互层，同时修复以下问题。

| 优先级 | 发现的问题 | 本次处理 |
| --- | --- | --- |
| P1 | 正文直接交给 Zepto `.html()`，其处理链支持脚本执行；图片和转发提示还存在字符串拼接 | 富文本改为惰性解析、元素/属性白名单重建；网址限制为 HTTP(S)，图片用 DOM 属性赋值。保留原始数据库内容 |
| P1 | 暂停服务后，任务仍可能持有数据库，其他页面可删除或导入数据 | 数据库管理和任务创建/启动共用 Web Locks；维护时检查当前任务、队列和状态，暂停任务也不能删除 |
| P1 | 数据库导出包含旧账号 Cookie、任务会话 | 导出账号去除会话字段，任务仅保留 ID、账号和创建时间；新账号记录、恢复及最近任务摘要也不再保存这些不必要的凭证 |
| P2 | 快速切分类、翻页时旧请求继续向当前容器追加内容；重复挂载图片事件 | 每轮渲染使用独立参数快照和脱离页面的容器，仅最新请求提交；统一移除旧监听，并在结束时关闭数据库连接 |
| P2 | 分页“下一页”以当前可见页码窗口的尾部判断，导致中间页不能继续 | 重写分页器，以总页数判断边界；支持有效页码检查和回车跳转 |
| P2 | 任务、迁移、导出按钮可被连续提交；零选择导出会直接关闭窗口 | 统一异步操作锁、加载态、明确报错；任务选项保留，未成功前不关闭 |
| P2 | 任务结束后进度立即消失，失败原因只留在后台日志 | 保留最近任务摘要、各项完成/失败/未执行状态及失败原因；登录等整单错误也呈现在任务中心 |
| P2 | RPC 断线后只能刷新，未响应的调用可能永久挂起 | 页面复用连接，挂起调用在断线/超时后结束；后续请求可重连，已提交的修改不会自动重放；RPC 限定为公开操作，禁止直接调用内部方法绕过维护锁 |
| P2 | 设置 API 未检查 `runtime.lastError`；本地保存成功、后台应用失败混为一谈 | 准确区分保存失败与应用待生效，校验请求间隔，提示未保存修改，调试日志开关立即响应 |
| P2 | 主页地址的未锚定正则可匹配伪造域名或 query 中的豆瓣链接 | 使用 URL 解析并验证域名、凭据、路径和用户标识 |
| P2 | 单个账号的损坏 JSON 会使整批恢复中断，已有成功结果无法完整汇报 | 按账号隔离错误、继续后续恢复，输出成功和失败清单；既有账号不覆盖 |
| P2 | 慢速正文请求在关闭窗口后重新弹出，或覆盖新详情 | 详情请求使用版本标记，关闭或切换后旧结果不再展示 |

## 页面与结构

- **备份首页**：账号数量、最近成功更新时间、账号搜索、明确的首份备份引导与“翻阅档案”入口。刷新保留页面，不再整页跳转。
- **新建备份**：项目卡片、已选数量、全选/半选反馈、其他账号地址校验、重复提交保护、错误内联显示。保留原有反爬提示和图片同步选择。
- **资料浏览器**：统一分类导航、条目数量、25/50/100 条分页、当前页文字筛选、历史记录标记、空状态和可重试错误状态。全文检索仍可通过 Excel 完成；页面筛选明确标注为当前页。
- **任务中心和设置**：保留数字进度与任务行复用，增加最近任务结果、可见失败原因、断线重连入口和保存状态。
- **工具栏弹窗**：用原生按钮替换不可键盘操作的菜单，显示后台状态和错误，提供任务中心直达入口。
- **可访问性**：共享焦点约束、Esc/遮罩关闭、关闭后返回触发按钮；导航和标签有 ARIA 状态，分类支持键盘。覆盖 390 px 窄屏与减少动态效果偏好。
- **代码拆分和加载**：共用样式、异步操作/弹窗管理、内容清洗、分页各自独立。Excel 导出移至 `exporter.js`，大体积 XLSX 库按导出需要加载；设置页不再导入整个后台任务图和 HTML 解析器。
